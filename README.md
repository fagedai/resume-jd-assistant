# JD 匹配助手（Chrome 扩展）

上传简历，用 DeepSeek 生成「简历画像」保存在本地；打开任意岗位 JD 页面，一键分析匹配度、投递成功率，并生成简短的打招呼语。

## 功能

- **简历画像**：上传 PDF（或粘贴文字），AI 提取为结构化画像并保存在本机
- **JD 匹配**：打开 JD 页面 → 分析匹配度评分、投递成功率、命中点 / 差距点、简历优化建议、面试准备提示
- **打招呼语**：匹配分析后一键生成 50～80 字的招呼语，可复制
- **匹配历史**：最多保留 5 条，新的自动覆盖最旧的

## 安装步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角「开发者模式」
3. 点左上角「加载已解压的扩展程序」
4. 选择本文件夹（`resume-jd-assistant`）

> 也可以把整个文件夹拖进扩展页安装。

## 使用步骤

1. 点工具栏里的「JD 匹配助手」图标
2. 在「简历」页填入 DeepSeek API Key（到 https://platform.deepseek.com 获取），点「保存」
3. 上传 PDF 简历（或粘贴文字），点「分析简历（生成 AI 画像）」
4. 打开一个岗位 JD 网页 → 点插件图标 → 切到「匹配」页 → 点「分析当前页面 JD」
5. 看完结果后点「生成打招呼语」，再点「复制」

## 小技巧

- 分析 JD 前，**先用鼠标选中 JD 正文**，结果会更准（插件会优先用你选中的文字）
- 扫描版 / 图片型 PDF 解析不出文字，用「手动粘贴」兜底

## 隐私与安全

- API Key 和简历画像只保存在本机 `chrome.storage.local`，**不会**同步到云端
- 简历原文在本地解析，只会把「结构化画像 + JD 文本」发送到 DeepSeek API 用于分析
- 「投递成功率」是 AI 估算，仅供参考

```
├── popup/
│   ├── popup.html       # 弹窗界面
│   ├── popup.css
│   └── popup.js         # 弹窗逻辑
├── lib/
│   ├── pdf.min.js       # pdf.js 本地解析 PDF
│   └── pdf.worker.min.js

```
